# Auto-sharing

Auto-sharing adds a small hook to each agent's settings (a backup is made first). When a connected
chat finishes a reply, the chats it is connected to get a short update **with their next message**:
what was asked, what was done, which files changed.

Nothing is sent anywhere: updates go from one chat's files to another's on this computer.

Turn it off at any time with **Crosstalk: Turn off auto-sharing**.
