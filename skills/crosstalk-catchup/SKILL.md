# Catch up on the other chats

1. `crosstalk_flightlog` with no `chat` lists recent chats. Take the ones in this folder updated since
   this chat's last message (or today), other than this one.
2. For each, read its newest asks: `chat` and `last: 10`.
3. **Report per chat:** what it set out to do, what it finished, what's still open, the files it
   changed.
4. **Then what matters here:** files both chats changed (possible conflicts), decisions that change
   this chat's plan, anything to pick up. Keep it short.
